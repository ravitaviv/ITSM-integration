# ITSM integration

A small mock of an AI agent getting just-in-time database access that is justified by an open ITSM incident.
Everything is simulated and kept in memory.

```
npm install
npm start     # http://localhost:3000
npm test
```

Live demo, running entirely in the browser: https://ravitaviv.github.io/ITSM-integration/
`npm run build:pages` rebuilds `docs/` (the GitHub Pages site).
